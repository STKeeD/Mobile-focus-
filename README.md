# MobileFocus

MobileFocus is a lightweight, mobile-first focus timer designed to help students, creators, and anyone doing focused work stay productive.

## Features

- 25-minute focus sessions
- 5-minute break mode
- Start, pause, and reset controls
- Completed-session tracking
- Session count saved locally in the browser
- Responsive mobile-friendly interface
- No account or API key required

## How to use

1. Open MobileFocus in your browser.
2. Select Focus or Break mode.
3. Press Start.
4. Work until the timer finishes.
5. Take a break and repeat.

## Technology

MobileFocus is built with vanilla HTML, CSS, and JavaScript. It has no external dependencies.

## Project status

MobileFocus is an early-stage open-source project. Improvements and contributions are welcome.
